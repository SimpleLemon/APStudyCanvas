# Approved implementation plan

1. Foundation: shared shell/routing/theme, Settings-only preview lifecycle, module mount/route-update/dirty-query/dispose contract and verified account context. Persistent Settings/Grades/Planner/Notes plus existing Study entry. Header search Canvas+local notes, fullscreen/close, real notifications. Preserve Settings interior/save/account/palette. Release every preview transform/observer/shield on exit; dim underlying Canvas, preview sharp. Narrow hide preview first. Dirty/focus/Escape/Back guards.
2. Planner connection: verified Nest gating, capability/consent states, existing calendar API adapter and mutations, stale/account guards, explicit deduplicated import preserving originals. No backend changes/new sync protocol.
3. Planner UI after adapter: remembered Sunday week default/view/date; day hourly+all-day+now+task list; seven-column week overlaps/shared labels; month adjacent dates/overflow day. Nest compact toolbar/filters/colors/details. Personal create/edit/move/resize/delete with 15min snap/1h default and keyboard/form alternatives; authoritative due dates separate. DST/errors/failed drafts preserved. No auto schedule/5-day/recurrence/sharing.
4. Notes after Foundation (parallel with Planner connection): searchable adjacent list/editor, course filters, recent/title, association, explicit save/trash/restore/excerpts/status, failed drafts and dirty guard, narrow list→editor/back. Existing scoped local text storage; no AI/rich text/Study conversion.
5. Grades domain after Foundation (parallel with Planner UI as slots allow): shared read adapter/chart datasets/scenario compatibility; preferences separate, no invented final grade history.
6. Grades UI after domain: overview current grades/GPA/credits/goals/links, class Overview/Assignments/Graphs/What-if and breadcrumb; same analytics on popup/native page. Guided course→metric→date range→supported type→generate/update. Presets scores over time line/points, score histogram, group bars; accessible table/tooltips/keyboard. Current/scenario supported comparison, estimates vs official and unsupported rules. Preserve what-if; no transcript/AI/multiseries.
7. Integration: assemble routes/manifests, risk tests, bounded visual round/fixes/confirmation, full extension/static/Firefox once, real Nest roundtrip if possible, generated-output review and commit, disposable task cleanup.

## Ownership
Foundation defines module contract before feature dispatch; feature workers only assigned modules/styles/tests/own task record. Shared wiring/manifests reserved for Integration after Foundation. All workers commit and report summary/path/IDs, not logs. At most two concurrent Sol medium tasks in worktrees.
