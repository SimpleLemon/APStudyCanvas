    What Canvas calendar sync can access

    With per-account consent, APStudyCanvas can read the full Canvas history available through the Canvas API and continue ongoing reads for that account.

    Personal event updates, planner updates, and selected item mirroring each require separate permission. When Nest sharing is enabled, synced items are automatically included in Nest shares and ICS.

    No Canvas data uploads before per-account consent for the current sync version. You choose consent separately for each Canvas account.
