# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
APStudyCanvas adds a cohesive student workspace to Canvas for settings, planning, local notes, grades and a Study placeholder.

## Capabilities and Constraints
Approved redesign: preserve Settings interior and save/account behavior, Study entry and existing records (the shared Study panel currently says “Coming soon.”), account-scoped local persistence and backwards compatibility. Planner requires verified Nest identity, existing consent/capability gates and existing calendar APIs. Canvas deadlines remain authoritative; scheduled work is a separate personal block. Notes use explicit local text saves. Grade charts derive only supported datasets and label estimates. No backend change, push or deployment.

## Brand Commitments
Preserve incumbent Settings typography and navy/gold/white-parchment palette. The approved sketch defines surrounding brand/search/navigation shell and Settings-only live preview.

## Accessibility & Inclusion
Keyboard alternatives to calendar gestures, dirty-leave guards, focus restoration, narrow layouts, theme matching, equivalent chart tables and honest failure states.

## Evidence on Hand
Approved user implementation brief summarized in docs/task-records/redesign-plan.md. Existing code is implementation evidence; Nest calendar reference is read-only. No invented live integration success or notification state.
